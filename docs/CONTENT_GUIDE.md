# Venuvella Content Guide

## Editorial standard

Create original, useful content with clear selection criteria and practical context. Do not fabricate reviews, testimonials, ratings, prices, discounts, specifications, awards or endorsements.

## Article workflow

1. Create draft.
2. Assign category and author.
3. Add editorial blocks.
4. Add SEO title/description.
5. Review links, images and disclosures.
6. Publish only when the content is complete and verified.

## Demo content

Seed records are development examples and should be replaced or clearly marked before a public launch.
